# 💰 Spendly  
### Mini Project: Expense Tracker

Spendly คือเว็บแอปสำหรับ **จดบันทึกรายรับ-รายจ่าย** แบบเรียบง่าย  
พัฒนาขึ้นเพื่อใช้เป็น **Mini Project** โดยเน้นการจัดการการเงินส่วนบุคคล  
ผู้ใช้สามารถเพิ่ม แก้ไข และลบรายการรายรับหรือรายจ่ายได้  
**ระบบนี้ไม่มีขั้นตอน Login / Register** ทุกการใช้งานเป็นแบบ local

---

## 📋 Project Overview
Spendly เป็นแอปสำหรับติดตามการเงินและการใช้จ่าย  
แสดงสรุปยอดเงิน รายรับ รายจ่าย และรายการ Expenses  
เหมาะสำหรับฝึกพัฒนา Web Application ด้วย **Next.js + Node.js / Express**

---

## 🛠 Tech Stack
- **Frontend**: Next.js (React), TailwindCSS  
- **Backend / Database**: Node.js, Express, หรือ API service ที่กำหนด  

---

## ✨ Features

### 🏠 Dashboard
- แสดงสรุปยอดเงิน:
  - รายรับทั้งหมด
  - รายจ่ายทั้งหมด
  - ยอดคงเหลือ
- แสดงกราฟสรุปการใช้จ่ายแบบง่าย
- เห็นภาพรวมการเงินทันทีที่เปิดเว็บ

---

### 💸 Expenses
- เพิ่มรายการรายรับหรือรายจ่าย
- แก้ไขรายการที่มีอยู่
- ลบรายการที่ไม่ต้องการ
- ข้อมูลของแต่ละรายการ:
  - ชื่อรายการ
  - จำนวนเงิน
  - ประเภท (Income / Expense)
  - หมวดหมู่

---

### ❌ No Authentication
- ไม่มีระบบ **Login / Register**
- ทุกฟีเจอร์ใช้งานแบบ local หรือ per-user
- เหมาะสำหรับทดลองใช้งานหรือฝึกพัฒนา Web App
